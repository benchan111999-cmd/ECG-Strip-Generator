# Data sources

## Current status

No dataset is registered, downloaded, or validated by Milestone 0. The approved
plan lists the intended source portfolio; it is not a completed source audit.

## Registry and licensing

Milestone 2 will verify each source's official version, licence, citation,
attribution, lead characteristics, annotations, and limitations before download.
The project's code licence does not grant rights to third-party recordings.

## Data lifecycle

Stage downloads, verify completeness and checksums, then promote atomically to
immutable raw storage. Distinguish official checksums from locally observed ones.
Local data and generated catalogs remain outside Git.

## Planned first real-data slice

Milestone 3 begins with NSRDB and PTB-XL, following the approved plan. Outputs
remain candidates until the separate human review gates are satisfied.
